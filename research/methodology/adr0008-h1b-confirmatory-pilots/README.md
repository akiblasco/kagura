# ADR 0008 confirmatory-method pilots (methodology archive)

**Synthetic data only.** Nothing here reads `data/`. These are the simulations behind
ADR 0008 §4–§5, which showed that no evaluated method can test H1b's confirmatory claim
at α = 0.025. They are **methodological findings, not evidence about USD/JPY.**

This is archived research code, kept as it was run, and is not part of the `kagura`
package. Ruff excludes it (`pyproject.toml`), and mypy and pytest never reach it.

## Reproduce

```bash
research/methodology/adr0008-h1b-confirmatory-pilots/run_all.sh <empty-scratch-dir>
```

The script works like this:
- It copies the code into the scratch directory and runs every script there, so nothing
  is written into the repository.
- It then compares each printed output with `reference_outputs/`, ignoring the timing
  columns.
- It exits 0 only if every output matches exactly.
- A full run takes about 40 min on 10 cores.

Reference environment:

| Item | Version |
|---|---|
| Python | 3.12.8 |
| numpy | 2.5.3 |
| scipy | 1.18.1 |
| statsmodels | 0.15.0 |
| pandas | 3.0.5 |
| Machine | Apple M2 Max, macOS |

The environment is the project's `uv.lock`. A different numpy or BLAS may change the last
printed digit.

Verified on 2026-10-23: a clean `run_all.sh` reproduced every reference output.

## Changes from the code as originally run

1. **Import paths.** `sys.path` entries changed from `../sim` to `../ak_bounds`, matching
   the renamed folder.
2. **`ak_calib_pilot.py` crash guard.** The original crashed when no attainable level
   achieved .025 in a cell, which is the B1 finding itself. It now prints "none attainable"
   and P(p ≤ 1/438). The numbers are unchanged from ADR 0008 revision 3 §3.2–§3.6.
3. **New files.** `check_ak_fast.py` and `ww_tables.py` are new:
   - `check_ak_fast.py` replaces an interactive check;
   - `ww_tables.py` replaces inline commands that first produced the WW tables. Its output
     is byte-identical to the original tables.

## What is excluded

- `.npy` result arrays: 20 MB, regenerated by the scripts.
- Downloaded papers and extracted text.
- CRAN package sources.
- Scratch logs.

The papers and packages are cited in ADR 0008 §12.

## Errata against the superseded reports

These reports are in `docs/decisions/superseded/0008/`.

- **Revision 4 report:** the values cited as "Table 10" (15.62 / 0.10) are from WW (2014)
  **Table 11** (IM-OLS).
- **WW pilot report §6:** "559 months" for 1970-01…2026-07 should read **679**.
- **Script paths:** the reports refer to `sim/` and `sim2/` in a session scratch directory.
  Those correspond to `ak_bounds/` and `wagner_wied/` here.
