# Textbook

Concepts taught through KAGURA's own problems, from beginner intuition to intermediate application.
Each chapter gives intuition, the formal mathematics with every symbol and algebraic step, worked
examples on verified KAGURA outputs, charts, knowledge checks, common mistakes, practice problems
and separate solutions. Illustrative examples are labelled as such.
